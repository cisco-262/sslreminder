Features

The details behind certificate health.

A clear countdown for everyday monitoring, with technical evidence when a certificate needs a closer look.

Daily cloud certificate checks

Public SSL/TLS endpoints are checked daily in the cloud. Automatic monitoring continues while the app is closed.

X.509 certificate chain

Inspect available root, intermediate and leaf certificate details, including SHA-256 fingerprints, key types and signatures.

SAN coverage and matching

See protected names and whether the checked hostname has an exact match or wildcard coverage. Name matching and trust checks are separate.

TLS protocol and cipher suite

Review the negotiated TLS version and cipher suite alongside certificate key length and signature algorithm.

Expiry and failure alerts

Receive iPhone push notifications for approaching expiry and supported certificate check failures through Apple Push Notification service.

Custom reminder schedules

Choose global reminder days or override them for an individual target, including an earlier reminder for short-lived certificates.

Batch paste and import

Paste multiple domains or HTTPS URLs, including custom ports. Preview parsed targets and validation results before adding them.

Issuer grouping and expiry sorting

Organize certificates by issuer or sort by remaining days so the next renewal is easier to find.

Certificate health PDF reports

Export a white-background report with certificate details, available chain evidence and a conclusion based on the check results.

CSV export and JSON backup

Export an inventory for spreadsheet use or back up target configuration in JSON for later import.

Home Screen widgets

View expiry categories and certificate status from your Home Screen, using the latest available monitoring snapshot.

Public endpoints, custom ports

Monitor standard HTTPS port 443 or another publicly reachable TLS service port. No private keys or server passwords are required.

X.509 and TLS details

A countdown backed by certificate evidence.

When the date alone is not enough, follow the available trust chain and inspect the TLS connection details on a larger iPad screen.

  • Root, intermediate and leaf certificate details
  • SHA-256 fingerprints, public keys and signature algorithms
  • SAN names with exact or wildcard hostname matching
  • Negotiated TLS protocol and cipher suite

Chain details depend on the evidence available from the endpoint. SAN coverage describes name matching, not a guarantee of trust or security.

FAQ

Common questions

How many certificate targets are free?

New users receive 3 free target slots. Eligible existing users keep their 15-slot free allowance.

Do I need to purchase analysis features?

No. Certificate analysis features are included. One-time in-app purchases add certificate monitoring capacity.

How often does monitoring run?

Automatic cloud certificate checks run daily. This is certificate monitoring, not continuous website uptime monitoring.

What does the trust chain view show?

Available root, intermediate and leaf certificate details, trust results, fingerprints and cryptographic metadata. The evidence available can vary by endpoint.

What does SAN matching mean?

It checks whether the hostname matches a name covered by the certificate, exactly or through a wildcard. Trust and expiry are evaluated separately.

Can I customize expiry reminders?

Yes. You can set a global reminder schedule and override it for individual certificate targets.

Can I export reports and back up targets?

Yes. Export PDF certificate reports, CSV inventory or JSON target backups. JSON targets can be imported again.

Can I monitor private LAN or VPN-only services?

The cloud checker needs a publicly reachable endpoint and port. Services accessible only through LAN or VPN may be unreachable. OpsHome NOC supports broader private-network monitoring.
