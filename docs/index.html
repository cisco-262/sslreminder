Frequently Asked Questions

Do I need an account to use SSL Reminder?

No. SSL Reminder does not require sign-up. You can monitor your certificate targets without creating an account.

How many certificates can I monitor for free?

You can monitor up to 15 SSL certificate targets for free.

Does SSL Reminder monitor private network certificates?

Cloud monitoring is designed for public SSL certificates. Private LAN or VPN-only targets are not suitable for long-term cloud monitoring in SSL Reminder.

What happens when a certificate is about to expire?

SSL Reminder sends iPhone push notifications before expiry, including 14-day, 7-day, 1-day, and expiry-day reminders.

What if I need full monitoring for private services or homelab infrastructure?

If you need uptime monitoring, private service monitoring, Docker Probe, Synology, Proxmox, Linux host monitoring, or a full operations view, please use OpsHome NOC.

Can I monitor HTTPS services on non-standard ports?

Yes. SSL Reminder can check public HTTPS services on custom ports, not only port 443. The target still needs to be reachable from the public Internet for cloud monitoring.

What does Certificate Health check?

Certificate Health can surface issues such as self-signed certificates, untrusted certificate chains, hostname or domain mismatch, expiry risk, and failed checks.

Can I export certificate information?

Yes. SSL Reminder can export certificate detail information as a PDF and provides import/export tools for monitored targets.
