关于 SSL Reminder

SSL Reminder 是 OpsHome 构建的一款专注 SSL 证书到期提醒的 iPhone 应用。

它是什么

SSL Reminder 帮助开发者、站长和 homelab 用户监控公开 SSL/TLS 证书的到期时间。它刻意保持轻量：添加证书目标、查看状态，并在到期前收到推送提醒。

为什么需要它

证书到期问题平时不显眼，但一旦发生就可能影响网站、API、控制台或个人服务。SSL Reminder 提供低成本的可见性，避免完全依赖人工记忆。

OpsHome 产品体系

OpsHome 构建面向实际运维可见性的工具。SSL Reminder 是产品体系中专注证书监控的轻量工具；OpsHome NOC 则覆盖更完整的正常运行时间、私有服务、Docker Probe、Synology、Proxmox、Linux 主机、容器和 homelab 运维。

官方产品身份

SSL Reminder 的官方网站是 ssl.opshome.run，iPhone 应用通过 Apple App Store 正式提供。这两个入口指向同一个 SSL Reminder 产品，并明确属于 OpsHome 产品体系。

刻意保持专注

SSL Reminder 不试图替代完整监控平台，而是专注公网 SSL/TLS 证书的到期、健康状态、提醒、自定义 HTTPS 端口、报告以及监控目标整理。需要私有基础设施和完整服务监控时，则使用 OpsHome NOC。
