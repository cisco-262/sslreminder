核心功能

到期日期之外，还有技术依据。

日常查看清晰的到期倒计时，需要排查时再深入证书链、域名覆盖和 TLS 连接信息。

每日云端证书检测

云端每日检测公网 SSL/TLS 服务。启用自动监控后，即使 App 未打开，也会继续进行云端检查。

X.509 证书链解析

查看可用的根证书、中间证书和站点证书详情，包括 SHA-256 指纹、密钥类型和签名算法。

SAN 覆盖与域名匹配

列出证书保护的名称，识别当前主机名是否精确匹配或受通配符覆盖。域名匹配与信任验证分别评估。

TLS 协议与密码套件

查看握手协商的 TLS 版本、密码套件，以及证书的密钥长度和签名算法。

到期与检测失败推送

通过 Apple 消息推送服务，将即将到期和支持的证书检查失败通知发送至 iPhone。

自定义提醒阶梯

设置全局提醒天数，也可为单张证书单独配置，让短期证书提前进入续期检查流程。

批量粘贴与导入

批量粘贴域名或 HTTPS URL，支持自定义端口。添加前预览解析结果与输入校验提示。

按签发商分组与到期排序

按签发商整理证书，也可按剩余天数排序，快速定位下一张需要续期的证书。

证书健康 PDF 报告

导出白底专业报告，包含证书详情、可用的证书链证据，以及基于检测结果形成的结论。

CSV 导出与 JSON 备份

导出证书清单用于电子表格归档，也可通过 JSON 备份监控目标配置并重新导入。

桌面小组件

通过桌面小组件查看到期分层和证书状态，展示最近一次可用的监控快照。

公网服务与自定义端口

检测标准 HTTPS 443 或其他公网可达的 TLS 服务端口，无需提供证书私钥或服务器密码。

添加或粘贴监控目标

02

04

X.509 与 TLS 技术详情

倒计时背后，是可查看的证书证据。

当到期日期不足以解释问题时，可以在 iPad 大屏上沿证书链逐级查看，并核对 TLS 连接信息。

  • 根证书、中间证书与站点证书详情
  • SHA-256 指纹、公钥和签名算法
  • SAN 名称列表与精确、通配符匹配
  • 握手协商的 TLS 协议与密码套件

证书链详情取决于服务端可获取的证据。SAN 覆盖仅说明名称匹配，不代表信任或安全保证。

FAQ

常见问题

免费提供多少个证书额度？

新用户赠送 3 个监控额度，符合条件的老用户保留原有 15 个免费额度。

证书分析功能需要单独购买吗？

不需要。证书分析功能全部开放，一次性内购用于增加证书监控容量。

云端多久检测一次？

自动云端证书检测每日运行。这是证书监控，不是持续的网站可用性监控。

信任链视图展示什么？

展示可用的根证书、中间证书和站点证书详情，以及信任结果、指纹和密码学信息。不同服务端提供的证据可能不同。

SAN 匹配意味着什么？

判断主机名是否精确匹配证书保护的名称，或是否受通配符覆盖。证书信任与到期状态会分别评估。

可以自定义到期提醒吗？

可以。支持全局提醒阶梯，也可为单张证书设置独立提醒天数。

可以导出报告和备份目标吗？

可以。支持 PDF 证书报告、CSV 清单和 JSON 目标备份，JSON 目标可以重新导入。

可以监控局域网或仅 VPN 可访问的服务吗？

云端检测需要公网可达的服务和端口，仅在 LAN 或 VPN 内可访问的服务可能无法检测。更完整的私网监控可使用 OpsHome NOC。
